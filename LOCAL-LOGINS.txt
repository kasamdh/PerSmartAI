START EVERYTHING
----------------
1. Start Docker Desktop and wait until it says it's running.
2. In the project folder (C:\Users\kasam\Projects\PetSitter):
      npx supabase start          (backend)
      npm run db:reset            (fresh test data; visits are relative to now)
      npm run mobile              (app; or: cd apps/mobile, npx expo start --go --lan --port 8082)
      npm run web                 (admin website, in a second terminal)


STOP EVERYTHING
---------------
Press Ctrl+C in the app and website terminals, then:
      npx supabase stop
